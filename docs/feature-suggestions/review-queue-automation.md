# Feature Suggestion: Review Queue Automation

## Status

Cancelled. Foundry's owner-decision inbox owns bounded approval requests and
Postiz owns draft review, scheduling, and publication. Reel Pipeline must not
recreate either system.

## Preserved rationale

The useful requirement was traceability between source evidence, review,
render, publication, and measured outcomes. Canonical missions and safe
evidence receipts now provide that linkage in Foundry without another queue.
