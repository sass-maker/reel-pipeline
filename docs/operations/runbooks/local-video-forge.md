# Local Video Forge (parked)

Local Video Forge was the Apple Silicon LTX evaluation and cross-machine queue.
Its setup and execution commands were removed from the supported package surface
on 2026-08-20 because local frontier generation did not clear the accepted-output
bar for the maintenance and review cost.

The implementation, prior receipts, and machine-local weights are retained for
historical reproducibility. They are not an active production path, and this
document is not a setup guide. See
[`ADR 0006`](../../architecture/decisions/0006-cost-capped-media-generation-boundary.md)
for the current boundary: manual imports, $0 automatic paid generation spend,
and separate operator approval for every paid generation job.
